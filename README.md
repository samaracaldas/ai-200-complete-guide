# AI-200 — Guia Completo de Estudos

Guia interativo de estudos para a certificação **Azure AI Cloud Developer Associate (AI-200)** da Microsoft.

🔗 **[Acessar o guia](https://samaracaldas.github.io/ai200-guia)**

---

## O que tem dentro

- **27 tópicos** cobrindo todos os domínios do exame
- **80+ questões** com respostas expansíveis
- **Casos de uso reais** por tópico
- **Quando usar / evitar** cada serviço
- **Código comentado** em Node.js, TypeScript, SQL e KQL
- **Analogias** para fixar o modelo mental
- **Táticas de aprendizado** práticas
- **Fontes e recursos oficiais** com links diretos
- Progresso salvo automaticamente no navegador
- Layout responsivo — funciona no celular

## Domínios cobertos

| Domínio | Peso |
|---|---|
| Containerized Solutions (ACR, Container Apps, KEDA, AKS) | 20–25% |
| AI Data Management (Cosmos DB, PostgreSQL + pgvector, Redis, RAG) | 25–30% |
| Connect & Consume Azure Services (Service Bus, Event Grid, Functions) | 20–25% |
| Secure, Monitor & Troubleshoot (Key Vault, Managed Identity, OpenTelemetry, KQL) | 20–25% |

## Como usar

Abra o `index.html` diretamente no navegador — sem instalação, sem dependências.

Ou acesse online: **[samaracaldas.github.io/ai200-guia](https://samaracaldas.github.io/ai200-guia)**

- **Nota mínima:** 700/1000
- **Tempo:** 150 minutos
- **Substituiu:** AZ-204 (aposentada em julho de 2026)
- **Practice Assessment oficial (gratuito):** [aka.ms/ai200practice](https://learn.microsoft.com/credentials/certifications/exams/ai-200/practice/assessment?assessment-type=practice&assessmentId=35)
